Desarrollo Web Principiante Duración: 20 Horas

Desarrollo Web Frontend con HTML5 y CSS3

Aprende a construir sitios y aplicaciones web accesibles, semánticas y responsivas utilizando exclusivamente estándares HTML5 y CSS3 moderno.

Inscribirme a este Curso ← Volver al Catálogo

Contenido del Curso y Módulos Secuenciales

Módulo 1: Fundamentos de HTML5 y Estructura Semántica

Lección 1 a 4

Etiquetas semánticas (<header>, <nav>, <main>, <footer>), estructura del documento y buenas prácticas de accesibilidad.

Módulo 2: Formulario Web y Validación Semántica

Lección 5 a 8

Elementos de formulario, asociación de etiquetas label for, tipos de entrada (input types) y atributos de validación nativos.

Módulo 3: CSS3 Puro, Flexbox y Grid Layout

Lección 9 a 12

Modelo de caja, especificidad de selectores, variables CSS en :root, maquetación flexible con Flexbox y rejillas con CSS Grid.

Módulo 4: Proyecto Final y Entregable Práctico

Evaluación

Construcción de un prototipo web responsivo y envío de evidencia práctica para calificación del instructor.
