Descripción de la Lección

En este módulo práctico aprenderás a utilizar el modelo de caja flexible (`flexbox`), alineando elementos horizontal y verticalmente mediante `justify-content` y `align-items`. Además, estructuraremos las variables globales `:root` para mantener una arquitectura de código CSS limpia y mantenible.
