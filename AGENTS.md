# Proyecto EduNova
Plataforma web SaaS tipo LMS (Learning Management System) para gestión de cursos, suscripciones, inscripciones, entrega de evidencias y emisión de certificados.

## Carpetas Protegidas (SOLO LECTURA)
- Las carpetas `BD/` y `referencia/` contienen activos previos del proyecto.
- PROHIBIDO modificar, renombrar o eliminar cualquier archivo dentro de `BD/` o `referencia/`.
- Puedes analizar `referencia/` únicamente como consulta visual (paleta de colores, tipografías Poppins e Inter y estilo de marca) cuando se construya `styles.css` en etapas posteriores.

## Stack Tecnológico Estricto
- Utilizar EXCLUSIVAMENTE HTML5 semántico, CSS3 puro y JavaScript puro (Vanilla).
- PROHIBIDO instalar o utilizar frameworks, preprocesadores o librerías externas (nada de React, Tailwind, Bootstrap, jQuery, etc.).
- Todo el código, comentarios, etiquetas y textos visibles de la interfaz deben estar en español.

## Reglas de Arquitectura y Calidad
- Usar etiquetas HTML5 semánticas (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- Todo campo de formulario (`<input>`, `<select>`, `<textarea>`) debe tener su etiqueta `<label for="...">` asociada correctamente y buen contraste visual.
- Centralizar todos los estilos en un único archivo `styles.css` en la raíz usando variables CSS en `:root` y clases reutilizables. No escribir CSS en línea ni dentro de los HTML.
- Utilizar exclusivamente datos ficticios realistas acordes al contexto educativo de EduNova.

## Protocolo de Interacción
- Antes de crear, modificar o eliminar cualquier archivo, muestra siempre el plan detallado y espera mi confirmación explícita.
- No inventes funcionalidades que no estén respaldadas por los documentos en `docs/`.

## Idioma
- Responder y hablar siempre en español
