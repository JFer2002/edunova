# Requisitos funcionales — EduNova

Requisitos derivados de las 20 historias de usuario (`docs/historias.md`). Cada RF está trazable a una HU de origen.

| Código | Descripción del Requisito Funcional | HU de Origen | Prioridad |
|---|---|---|---|
| RF-01 | El sistema debe presentar la landing pública de EduNova con la propuesta de valor, los beneficios principales y los accesos directos a registro, planes e inicio de sesión. | HU-01 | Must |
| RF-02 | El sistema debe ofrecer enlaces visibles a la página de registro, a la página de planes e inicio de sesión. | HU-01 | Must |
| RF-03 | El sistema debe permitir ingresar con correo y contraseña y validar las credenciales ingresadas. | HU-02 | Must |
| RF-04 | El sistema de be redirigir al dashboard correspondiente al rol autenticado tras un ingreso exitoso. | HU-02 | Must |
| RF-05 | El sistema debe mostrar un dashboard adaptado a Estudiante con tarjetas de cursos activos que incluyan barra de porcentaje de avance. | HU-03 | Must |
| RF-06 | El sistema de be mostrar en el dashboard de Estudiante un calendario mensual y una sección de próximas sesiones en vivo. | HU-03 | Must |
| RF-07 | El sistema debe ofrecer un buscador en tiempo real que filtre el catálogo de cursos y carreras técnicas. | HU-04 | Must |
| RF-08 | El sistema debe aplicar filtros de categorías y rutas sobre la lista de resultados mostrada. | HU-04 | Must |
| RF-09 | El sistema debe permitir a Instructores publicar cursos y editar su título, descripción y categoría. | HU-05 | Must |
| RF-10 | El sistema debe mostrar los módulos del curso en orden secuencial. | HU-05 | Must |
| RF-11 | El sistema debe ofrecer agenda interactiva de mentorías "tú a tú" con fecha y franja horaria. | HU-06 | Should |
| RF-12 | El sistema de be mostrar enlaces de sesiones en vivo y una sección de grabaciones en diferido. | HU-06 | Should |
| RF-13 | El sistema debe permitir cargar entregables prácticos (archivos, enlaces y notas) desde la página de inscripción. | HU-07 | Must |
| RF-14 | El sistema debe mostrar el historial de calificaciones con las entregas y calificaciones recibidas. | HU-07 | Must |
| RF-15 | El sistema debe mostrar el certificado digital emitido al alcanzar el 100% de avance de un curso o ruta. | HU-08 | Should |
| RF-16 | El sistema debe incluir en el certificado un código QR visible y respaldable. | HU-08 | Should |
| RF-17 | El sistema debe mostrar un comparativo visible de los planes (Explorador, Pro, Premium) con sus precios y modalidades. | HU-09 | Must |
| RF-18 | El sistema debe permitir seleccionar y confirmar una actualización del estado de membresía. | HU-09 | Must |
| RF-19 | El sistema debe ofrecer mensajería interna entre Estudiante e Instructor. | HU-10 | Could |
| RF-20 | El sistema debe mostrar un panel de notificaciones y alertas con recordatorios de clases o entregas. | HU-10 | Could |
| RF-21 | El sistema debe mostrar el calendario de sesiones en vivo programadas con su estado y capacidad disponible. | HU-11 | Should |
| RF-22 | El sistema debe permitir crear mentorías individuales con fecha, franja horaria y enlace de videollamada generado automáticamente, listándolas en la agenda del instructor. | HU-12 | Should |
| RF-23 | El sistema debe calcular automáticamente el porcentaje de avance en inscripción según los módulos del curso y mostrar la barra de progreso que refleje el avance calculado. | HU-13 | Must |
| RF-24 | El sistema debe mostrar el listado de usuarios con rol y estado visibles, permitiendo crear y desactivar usuarios. | HU-14 | Must |
| RF-25 | El sistema debe mostrar el listado de cursos pendientes de moderación y permitir aprobar o rechazar cada curso. | HU-15 | Should |
| RF-26 | El sistema debe permitir definir el tipo de plan, el precio y la modalidad (Mensual/Anual) y listar los planes configurados en la pantalla de gestión de planes. | HU-16 | Should |
| RF-27 | El sistema debe mostrar el calendario de clases programadas con enlace visible, capacidad definida y estado de cada clase. | HU-17 | Could |
| RF-28 | El sistema debe mostrar las métricas de visualización de los contenidos y el desempeño (progreso y calificaciones) por aprendiz o curso. | HU-18 | Should |
| RF-29 | El sistema debe mostrar alertas de entrega aceptada/rechazada y calificación recibida en el panel de notificaciones, así como alertas visibles de clases o sesiones próximas. | HU-19 | Could |
| RF-30 | El sistema debe mostrar el total de estudiantes matriculados bajo el convenio y los datos de distribución de ingresos (Revenue Share). | HU-20 | Could |
