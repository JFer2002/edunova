Lección 4.2

Consumo de APIs con Fetch y Promesas

RF-10 · Orden secuencial RF-12 · Sesiones y grabaciones

En esta lección aprenderás a realizar peticiones asíncronas a servicios externos y manejar las respuestas de forma segura.

[ Visualizador de contenido: Peticiones Fetch y manejo de errores ]

Acerca de esta lección

Utilizaremos el estándar fetch() para obtener datos de una API REST pública. Analizaremos el ciclo de vida de una promesa, el uso de .then(), .catch() y la sintaxis moderna async/await para simplificar el código asíncrono.
